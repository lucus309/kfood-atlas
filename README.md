# K-food Atlas

제품군별 수출 유망국 TOP3를 탐색하고 추천 근거를 비교하는 시장분석 웹 서비스입니다.

[서비스 열기](https://kfood-market-atlas-eugene.eugenekim24730.chatgpt.site/)

## 주요 기능

- 10개 제품군·195개 국가/지역 탐색, 제품군·기간 선택
- 구매력·수입시장·한국산 수입 변화·문화/소비 근거를 활용한 추천
- 시장 성장 그래프, 국가 상세, 경쟁 공급국, 후보 비교, CSV 내보내기
- 국가 조회·비교 도구를 사용하는 AI 질의응답과 출처 연결

## 실행

Node.js 22.13 이상이 필요합니다. Node.js 25.9에서 검증했습니다.

```sh
npm ci
npm run build
npm start
```

http://localhost:4173 에서 확인합니다. API 키 없이도 대시보드와 저장된 설명은 작동합니다. 실시간 질의응답을 사용하려면 `.env.example`을 `.env.local`로 복사하고 본인의 `OPENAI_API_KEY`를 설정하세요. 실시간 AI API에는 별도 사용 요금이 발생할 수 있습니다. API 키는 서버에서만 사용합니다.

```sh
npm test
```

14개 테스트 묶음으로 계산·기간 변경·결측·추천·챗봇 입력 검증 등을 확인합니다. 테스트는 실제 AI API를 호출하지 않습니다.

## 기술 및 구조

JavaScript ES Modules, HTML/CSS/SVG, Cloudflare Workers, D1, OpenAI Responses API 및 GPT-5.4, esbuild를 사용합니다.

- `dist/`: 프런트엔드 원본 코드와 가공 데이터
- `server/`: 데이터 조회 도구, AI API 서버
- `drizzle/`: DB 스키마
- `fixtures/`: 추천 결과 검증 기준
- `scripts/`: 빌드, 로컬 실행, 설명 생성

로컬 DB는 메모리 SQLite이며 재시작 시 초기화됩니다. 운영 호스팅 설정은 제외했습니다. 별도 호스팅 시 DB 바인딩과 서버 비밀값을 구성해야 합니다. 설명 생성 스크립트는 API를 호출하며 비용이 발생할 수 있습니다.

## 데이터와 분석 범위

UN Comtrade의 수출입·한국산 수입·공급국, World Bank WDI의 가계소비·인구, KOFICE의 문화 소비·식품 구매의향, WINA 및 공식 재수록 자료의 즉석면 소비, 한식진흥원의 도시별 조사, World Bank LPI의 물류 참고자료를 활용합니다. 정확한 출처·기간·범위는 각 JSON 메타데이터와 서비스의 데이터와 기준에서 확인할 수 있습니다.

제3자 데이터의 권리는 원 제공기관에 있으며 해당 기관의 이용 조건이 적용됩니다. 서비스가 사용하는 가공 데이터 스냅샷을 포함하며 전체 원자료 캐시와 수집 파이프라인은 포함하지 않습니다.

경제·수입시장 기본 비교는 4개 지표 동일 가중치입니다. 단일 추천은 구매력·수입시장·한국산 성과·문화/소비 관측 근거와 후보 조건으로 산출합니다. 국가별 관측 범위에 따라 실효 비중이 달라질 수 있습니다. 미확인은 0으로 채우지 않습니다. 문화는 한국 콘텐츠 경험자 대상이며 즉석면 소비는 모든 원산지 제품을 포함합니다.

현재는 관측 지표 기반 추천과 저장된 AI 설명, 실시간 근거 질의응답을 구현했습니다. 미래 수입 예측 모델과 분석·반증 에이전트 협업은 추가 개발 계획입니다. 테스트는 계산·동작의 재현성을 확인하며 실제 판매 예측력을 입증한 결과는 아닙니다.

## 코드 품질

[리팩터링 기준·구조·검증 기록](docs/CODE_QUALITY.md)을 참고하세요. 화면과 AI 서버는 `market-analysis.mjs`의 동일 분석을 사용하며 제품·기간별 결과를 재사용합니다. 그래프·표시 형식·국가명·CSV와 채팅 요청·저장·스트림·도구 실행은 역할별 모듈로 분리했습니다.

```sh
npm run format:check
npm run format
```

100가지 제품·기간 조합의 변경 전 결과와 추천·설명·CSV가 일치하는지 검사합니다. 추가 채팅 검증은 실제 API를 호출하지 않습니다.
